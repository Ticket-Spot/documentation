**Attendee Details** provides a quick way to view and manage information for each attendee during an event. Here, you can review their registration details, update their check-in status, access order information, and add internal notes as needed. 

This guide explains how to navigate the attendee information view and use each option effectively while managing event check-ins.

## Manage Attendee Actions

You can manage attendees directly from the attendee details view. This includes editing the attendee’s name and updating their attendance status based on their check-in activity during the event.

### Edit Name
Use the Edit Name option if you need to correct or update the attendee’s name. This helps ensure that attendee records remain accurate for reporting and check-in tracking.

<img 
  src="../assets/mobile-app/attendee-details/edit-name.gif" 
  style={{ maxWidth: "300px", height: "auto" }} 
  alt="edit-name"
/>

### Change Attendee Status
You can update the attendee’s status using the dropdown options:

- **Attending** – The attendee is expected to attend.
- **Checked-In** – The attendee has arrived and successfully checked in.
- **Not Attending** – The attendee is marked as not attending.

<img 
  src="../assets/mobile-app/attendee-details/status-change.gif" 
  style={{ maxWidth: "300px", height: "auto" }} 
  alt="status-change"
/>

These options allow you to keep the attendee list updated throughout the event.

> **Note:** The **Status changes** feature is only available for **live** events, and the options will **not** be visible once an event has **ended**.

## Review responses and signed waivers

Open an attendee from the event list or a scan result, then choose **Responses**. The tab can show the number of answers. Review each question and its saved answer; checkbox answers display their checked state. A missing answer is not the same as an unchecked response.

For waivers, check the recorded confirmation: **Acknowledged**, **Not acknowledged**, **Waiver signed**, **Confirmation incomplete**, or **No confirmation recorded**. When present, review the signer's name, time, and signature. Tap a signature to enlarge it. **View waiver** expands saved text; **View waiver document** opens the linked/uploaded document. An unavailable signature or failed document link does not establish that the waiver was completed.

Use the organizer [Attendee Dashboard](/attendee-management/viewing-attendee-details#questions) to review and edit ordinary answers. Signed waiver evidence is separate from ordinary editable answers.

## Check in everyone in an order

1. Open the attendee and tap **Order Details**.
2. Under **Tickets in Order**, review each ticket and its check-in state. Open an individual attendee when you need their details.
3. Choose **Check In All** when nobody has arrived, or **Check In Remaining** when some tickets are already checked in. The count identifies the remaining eligible tickets.
4. Review the result. Already checked-in tickets are skipped; records not marked attending are not included. If some fail, review those tickets and retry only the remaining eligible guests.

**All Tickets Checked In** means the displayed group is complete. **No tickets available to check in** can also appear when no eligible attending tickets remain; it is not proof that every record checked in successfully. The app reports partial failures separately.
