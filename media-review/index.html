Capture style and review sequence

1. Inventory completed. 2. Purple circle style and first page approved. 3. Refresh all remaining pages. 4. Review each capture and its placement; return to unavailable external accounts later.

Crop: app content only, with no browser chrome or address bar. Prefer 1440 × 900 desktop or 390 × 844 mobile capture at 2× density. Preserve useful navigation context and readable labels. Split dense panels into numbered crops.

Circles: consistent high-contrast circles or rounded outlines, 3–4 px at display size; at most three per frame; numbered badges tied to a caption. Never obscure labels.

GIF: one action, 6–10 seconds (12 maximum), 1.2–1.5× focus zoom, visible cursor/click cue, a short orientation pause and a 2-second result pause. Export a static poster for accessibility and motion preference. Keep controls and text readable before optimizing file size.

Real interface: capture actual Ticket Spot Demo UI. Do not redraw controls or generate synthetic product screenshots. Use synthetic demo attendees/orders; conceal secrets, OTPs and non-demo personal data. Every final frame must exclude browser URLs.

Acceptance: verify current labels, matching prose, readable crop, real Demo identity, correct circle placement and GIF outcome.
