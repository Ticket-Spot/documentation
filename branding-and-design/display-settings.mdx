---
title: "Widget display settings"
description: "Configure the information and actions shown on events, recurring-event browsing, pagination, and checkout step order."
---

Open **Design → Widget**, select your widget, then **All Settings → Display**. Search settings can take you directly to a control.

## Choose a section

| Section | What to configure |
|---|---|
| **Event details** | Event title/status, venue/address, online/Zoom details, ongoing events, session choices, availability icons, and RSVP form-only mode. |
| **Date & time** | Date and time format, start/end visibility, timezone label, and visitor-timezone conversion. |
| **Images** | Event image visibility, size, zoom, and carousel. |
| **Header & actions** | Widget header, event link, linked title, attend button, and rounded corners. |
| **Event description** | Summary/full description, character limit, More behavior, formatting, and right-to-left text. |
| **Event count & pagination** | Plan ceiling, all-events toggle, maximum count, order, Load more, and events per load. |
| **Recurring events** | Next occurrence versus expanded occurrences, date grouping, and skipping a single date/time option. |
| **Hosts & attendees** | Host/attendee sections, their labels, and host avatars. |
| **Visitor engagement** | Add to Calendar, external checkout embedding, event-page redirection, and new-tab behavior. |
| **Submit event request** | Submission button, label, and explanatory text. Configure the approval workflow in Site Settings. |
| **Workshops & add-ons** | Selection subtitle and maximum-reached message. |
| **Memberships** | Subtitle, image, validity, visit limits, and featured badge. |
| **Checkout & payment** | Ticket-first or combined date/ticket steps and optional installment information. |

The [complete display reference](./widget-display-reference) lists every control and its effect. [Event Filters](./filters) determines which events appear at all.

## Configure and test

1. Change one group of related controls and wait for saving to finish.
2. Preview a normal event and a recurring event.
3. Check event count and pagination with more events than fit in the first load. Show all does not override the plan limit.
4. Test the buy/attend button to confirm whether it opens checkout, an event page, or an external destination.
5. Test the selected checkout step order and session options on the installed widget.

Dates shown in the listing and dates shown in checkout have separate formatting controls. Hiding a field does not change the underlying event information.
