---
title: "Visitor search and filters"
description: "Give visitors keyword, date, category, language, and location controls for browsing your events."
---

Open **Design → Widget → All Settings → Visitor search & filters**.

Enable **Show event search** for a keyword box. Choose the venue, city, region, country, category, language, month, and week filters appropriate to your event data. See [every visitor-filter option](./widget-visitor-filters-reference).

Edit placeholders under **Text → Search filters**. Edit their appearance under **Design → Customize components → Visitor search & filters**. Automatic search-filter translation is under **Text → Event details**.

Wait for saving, then test selecting and clearing each filter on desktop and mobile. Visitors only search the events already included by the widget's [Event Filters](./filters), publication status, and applicable limits.
