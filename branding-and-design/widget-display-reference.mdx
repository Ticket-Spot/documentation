title: "Widget display options reference"
description: "Find every display control for event listings, dates, images, recurring sessions, checkout steps, memberships, and add-ons."
---

Open **Design → Widget → All Settings → Display**. Use the section names below or **Search settings**. These controls affect presentation and selection flow; configure ticket prices, capacity, and sales windows in the event editor.

**Show all available events** overrides **Maximum events to display**, but still respects the site's plan limit and event filters. **Show a 'Load more' button** reveals **Events per load**; it does not increase those limits. Turning on **Show every occurrence of a recurring event** changes which dates are listed.

**Choose tickets before choosing a date** takes priority over **Show tickets on the same step as dates and times**. Both apply to events requiring a date/time selection. With ticket-first selection, dates must have availability for all chosen ticket types. Date-first combined checkout displays tickets below the selected date/time.

For a multi-session event, **Offer an all-sessions pass** and **Offer single sessions** control the choices presented. If both are off, checkout selects the all-sessions option and skips date/time selection. Verify that choice against the event's [whole-event pass setup](/event-management/day-specific-tickets).

Some settings appear only after a related option is enabled: end time and time format need start time; city needs venue; event-link wording needs an event link; add-on, membership, and installment presentation needs the corresponding feature on the event. Optional installment notices do not remove the mandatory payment schedule and authorization.
