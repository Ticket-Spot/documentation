Display a Ticket Spot event calendar or ticket listing on a Squarespace page. You manage events in Ticket Spot and install the widget using Squarespace's code tools.

## Before you start

- You need permission to edit the Squarespace page and its custom code.
- Your Squarespace plan must support code injection and JavaScript. Squarespace currently lists **Core, Plus, Advanced, and some legacy plans** for these features; check its [code injection guide](https://support.squarespace.com/hc/en-us/articles/205815908-Customize-parts-of-your-site-with-code-injection) for your plan.
- Create and publish an event in Ticket Spot. For paid tickets through Ticket Spot checkout, [connect a payment provider](/account/get-paid). Free registration does not require a payment connection.

If your plan does not support the embed, you can add a normal Squarespace link or button to the event's public Ticket Spot page instead, if your Ticket Spot plan includes hosted event pages. Check [feature and plan availability](/account/feature-reference), then find the public link in [Event Details](/event-management/eventdetails).

## Get your Ticket Spot installation code

In Ticket Spot, open **Design → Widget**, select your widget in **Editing Widget**, then choose **Installation → Any Website**. Keep both generated snippets ready: **Step 1: Add Script to HEAD** and **Step 2: Insert Widget**.

For calendar and list layouts, follow the [widget layout guide](/branding-and-design/layout). The [general embed guide](/plugins/embed-on-your-website) explains the two snippets and checkout routes.

## Add the script and widget to Squarespace

1. In Squarespace, open the **Code Injection** panel. Paste the complete **Add Script to HEAD** snippet into **Header**, preserving any other code already there, then save.
2. Edit the page where your events should appear. Add a **Code** block and paste the **Insert Widget** snippet into it.
3. Use HTML mode and leave **Display Source** off so Squarespace renders the widget. Save the page.
4. Open the published page URL in a private browser window. Custom scripts may be disabled in the editor preview.

Squarespace documents the editor controls in its [code block guide](https://support.squarespace.com/hc/en-us/articles/206543167-Add-custom-code-to-a-page-with-code-blocks). The header script loads Ticket Spot; the page block controls where visitors see your events.

## Test registration

Check desktop and mobile, open the correct event, choose a ticket, and complete a registration. Confirm that the displayed date, price, and required questions are correct, then check the confirmation and ticket link. Find the attendee and order in Ticket Spot and, for a paid order, verify the payment with your connected provider.

This embed uses Ticket Spot's checkout and payment setup. Manage those settings in Ticket Spot and use the [launch checklist](/getting-started/launch-checklist) before sharing the page.

## Troubleshooting

If you see the code as text, turn off **Display Source** in the Code block. If nothing appears, check that your Squarespace plan permits scripts, both complete snippets are installed, and the selected widget includes a published event. Always check the published page outside the editor before changing the code.
