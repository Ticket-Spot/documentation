Use **Class** for a repeating lesson, fitness class, or learning session. The template starts weekly with a ticket named **Class Pass** and a suggested capacity of 20. The ticket name alone does not grant access to an entire course.

## Template starting point

| Setting | Initial choice |
|---|---|
| Schedule | Weekly |
| Admission | Paid tickets |
| First offer | Class Pass · suggested price 25 in your site’s currency |
| Capacity | 20 |
| Attendees choose a time | Not enabled |

These are editable suggestions, not recommended prices or venue limits. Replace the dates, price, and capacity with your own. See [how onboarding works](./overview#complete-onboarding).

## Choose the onboarding answers

Open **Create Event** in the selected workspace.

1. Select **Class** and name the class.
2. Review **Weekly**, choose the teaching weekdays, set the session start/end and **Repeats until**. Choose **Monthly** instead only when the class repeats on the same date each month.
3. Keep **Paid tickets** or switch to **Free RSVP**. Set the real class size and price, and give the ticket a name that states what one booking includes.

<Note>**Create my event** may publish immediately when the requirements are met. Use **Continue later** to finish setup as a draft. Review any plan or publishing message before sharing the event.</Note>

## Finish the event settings

| Where to go | What to configure |
|---|---|
| **Dates & Times** | Review the [recurring schedule](/event-management/datetime#recurring), including holidays or dates that need individual changes. |
| **Tickets** | Set session inventory and purchase limits. Explain whether the attendee is reserving one class. |
| **Additional Info** | Build your [class registration form](/event-management/additional-information) with the participant details or level choices you need. |
| **Memberships** | For a class package, configure duration, visit limits, and assigned class events. See [memberships and class packs](/memberships/overview). |
| **Email Communication** | Add preparation, equipment, venue, or online joining instructions and review reminders. |

## A recurring class is different from a class package

A recurring schedule supplies dates; it does not automatically make a single booking valid for all sessions. A ten-visit package needs a membership with the appropriate total and per-event visit limits. If each member must reserve a place, configure that separately under [membership event assignment](/memberships/assign-to-events). Membership duration does not create an automatically renewing subscription. For a one-off lesson, select **One day** or use [Workshop](./workshop).

## Check the attendee experience

- Select two different dates and confirm that each booking clearly identifies its session.
- Submit registration details for the participant, including orders containing more than one ticket.
- If using a membership, test eligible and non-member checkout and the visit limits.

Review the event’s saved status and [publish/share controls](/event-management/manage-events) when it is ready. Return to [all event types](./overview) to compare starting points.
