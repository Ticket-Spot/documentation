Use **Theatre** when the audience chooses seats for a performance. It starts with **Assigned seating** and an **Adult Ticket**. The template enables seating but does not build or attach a chart, so it stays a draft until you complete that work.

## Template starting point

| Setting | Initial choice |
|---|---|
| Schedule | One day |
| Admission | Assigned seating |
| First offer | Adult Ticket · suggested price 25 in your site’s currency |
| Capacity | 100 |
| Attendees choose a time | Not enabled |

These are editable suggestions, not recommended prices or venue limits. Replace the dates, price, and capacity with your own. See [how onboarding works](./overview#complete-onboarding).

## Choose the onboarding answers

Open **Create Event** in the selected workspace.

1. Select **Theatre**, enter the production name, and set the performance date and times.
2. Keep **Assigned seating** and enter the intended starting price and capacity.
3. Open the created draft and finish the venue, tickets, and chart before publishing. For additional performances, configure dates in the editor and check seating for each occurrence.

<Note>**Create my event** may publish immediately when the requirements are met. Use **Continue later** to finish setup as a draft. Review any plan or publishing message before sharing the event.</Note>

## Finish the event settings

| Where to go | What to configure |
|---|---|
| **Seat Charts** | Create and [publish a venue seating chart](/seating-charts/create-and-assign), including rows, sections, and seat categories. |
| **Tickets → Assigned Seating** | Select the chart. A category must exist on every bookable seat or area. |
| **Ticket → Seat Categories** | Map the categories each Adult, Child, or concession ticket can book, then set each price. |
| **Dates & Times** | For a run of performances, verify each date/time and its seating setup. Each occurrence has its own availability. |
| **Email Communication** | Include performance time, arrival instructions, and ticket actions for the audience. |

## One seat can offer several ticket prices

Adult and concession tickets can share a seat category. The buyer chooses the appropriate ticket for each seat; a category name is not itself a price. Follow [seat selection and pricing](/seating-charts/seat-selection) and review the summary for the exact row, seat, ticket type, and total. Assigned seating requires the supported plan and seating allowance. On Shopify, use the [Ticket Selector](/plugins/shopify-ticket-selector) and test the seat assignment through checkout.

## Check the attendee experience

- Choose seats from each price category and check the correct ticket options.
- For multiple performances, confirm selecting a seat on one date does not imply admission on another.
- Verify seat labels on the ticket and the admission result at check-in.

Review the event’s saved status and [publish/share controls](/event-management/manage-events) when it is ready. Return to [all event types](./overview) to compare starting points.
