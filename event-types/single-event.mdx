Use **Single Event** when none of the named activity templates fits and you need one occurrence. It starts with paid General Admission. Choose the actual admission method and build out the content in the full editor.

## Template starting point

| Setting | Initial choice |
|---|---|
| Schedule | One day |
| Admission | Paid tickets |
| First offer | General Admission · suggested price 25 in your site’s currency |
| Capacity | 100 |
| Attendees choose a time | Not enabled |

These are editable suggestions, not recommended prices or venue limits. Replace the dates, price, and capacity with your own. See [how onboarding works](./overview#complete-onboarding).

## Choose the onboarding answers

Open **Create Event** in the selected workspace.

1. Choose **Browse more templates → Advanced → Single Event**, then enter the event name.
2. Review **One day**, **Starts**, and **Ends**. An overnight event can finish on the following date; choose Several days only when that describes the access you intend.
3. Select **Paid tickets**, **Free RSVP**, or **Assigned seating**. Set the actual price and capacity, then choose **Continue later** to complete the editor in draft.

<Note>**Create my event** may publish immediately when the requirements are met. Use **Continue later** to finish setup as a draft. Review any plan or publishing message before sharing the event.</Note>

## Finish the event settings

| Where to go | What to configure |
|---|---|
| **Event Details** | Write the description, choose the category, set the timezone, and add event images. |
| **Venue & Location** | Choose physical attendance or supply online joining information. |
| **Tickets** | Review the first ticket and add other offers as needed. See the [complete ticket setup guide](/event-management/ticket-setup). |
| **Additional Info and Email Communication** | Collect the required attendee information and prepare confirmation/reminder messages. |
| **Design and installation** | Set your brand and choose a [website embed](/plugins/embed-on-your-website), Shopify integration, or hosted event page. |

## When to use another starting point

Use [Repeating Event](./repeating-event) for a schedule that repeats and [Multi-day Event](./multi-day-event) for one event spanning days. Use [Assigned Seating](./assigned-seating) when seat selection is central. **Start from scratch** is a different entry point: it opens the full editor without provisioning an event through the questions. The [event creation guide](/event-management/create-event-overview) remains the complete reference for editor steps.

## Check the attendee experience

- Confirm the event has the intended single occurrence and timezone.
- Check the admission method, price if any, and overall capacity.
- Review the public page, confirmation, and ticket before sharing the link.

Review the event’s saved status and [publish/share controls](/event-management/manage-events) when it is ready. Return to [all event types](./overview) to compare starting points.
